# javascript-racingcar-precourse

## 2주차 - 자동차 경주

### 구현할 기능 목록

- 사용자는 경주할 **자동차들의 이름**을 입력할 수 있다. 이는 쉼표(,)를 기준으로 구분된다.
  <br/>
  <br/>
- **자동차 이름 입력의 조건**은 아래와 같고, 조건이 지켜지지 않을 시 조건에 맞는 에러 메세지와 함께 Error을 반환한다.
  <br/>

  - 자동차의 이름은 5자 이하만 입력 가능하며 5자를 초과하거나 공백이라면 ‘[ERROR]: 자동차 이름은 1자 이상, 5자 이하여야 합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>예를 들어, 'pobi,,jae'나 ',,,A' 이런 식으로 입력이 들어오는 경우 쉼표를 기준으로 구분되어 생긴 공백을 방지하기 위함이다.
    <br/>쉼표로 구분된 이름 자체가 공백일 경우만 체킹한다. 즉, 만약 사용자가 '()()pobi,jae' 이런 식으로 입력을 했을 경우, 공백은 무시되고 pobi만 세어진다. (() -> 공백을 의미)
    <br/>

  - 자동차의 이름에는 특수문자와 공백을 제외한 모든 문자가 입력 가능하며 특수문자나 공백을 포함했을 경우 ‘[ERROR]: 특수문자와 공백은 자동차의 이름에 포함 될 수 없습니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>

  - 자동차 **경주**이기 때문에 입력된 문자열에서 쉼표가 하나도 없는 경우 ‘[ERROR]: 둘 이상의 자동차 이름을 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>
  - 자동차 이름 입력 자체를 하지 않은 경우 ‘[ERROR]: 자동차 이름을 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>
  - 자동차 이름은 중복이 될 수 없다. 중복이 확인되는 경우 ‘[ERROR]: 자동차 이름은 중복이 될 수 없습니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>

- 사용자는 자동차의 이름 뿐만 아니라, **자동차들의 이동 횟수**도 입력할 수 있다.
  <br/>
  <br/>
- 이동 횟수 입력 조건은 다음과 같고, 조건이 지켜지지 않을 시 조건에 맞는 에러 메세지와 함께 Error을 반환한다.

  - 만약 입력된 값이 0이나 음수라면 ‘[ERROR]: 시도할 횟수는 1 이상의 자연수여야 합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>
  - 만약 입력된 값이 숫자 외 다른 값이라면 ‘[ERROR]: 시도할 횟수에는 숫자만 입력 가능합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>
  - 만약 아무 입력을 하지 않았다면 ‘[ERROR]: 시도할 횟수를 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>

- 사용자가 입력한 시도할 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
  <br/>
  <br/>
- 자동차가 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
  <br/>
  <br/>
- 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
  <br/>
  <br/>
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있고, 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
  <br/>
  <br/>
- 만약 시도할 횟수 내의 모든 자동차가 전진을 하지 않았다면, 공동 우승이 아닌 우승자가 없다고 판단하며 **'결과: 우승자는 없습니다.'** 라고 출력한다.
  <br/>
  <br/>

### 입출력 요구사항

**입력**

- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)

```js
pobi, woni, jun;
```

<br/>

- 시도할 횟수

```js
5;
```

<br/>

**출력**

- 차수 별 실행 결과

```js
pobi : --
woni : ----
jun : ---
```

<br/>

- 단독 우승자 안내 문구

```js
최종 우승자 : pobi
```

<br/>

- 공동 우승자 안내 문구

```js
최종 우승자 : pobi, jun
```

<br/>

**실행결과 예시**

```js
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```
