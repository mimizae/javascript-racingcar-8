# javascript-racingcar-precourse

## 2주차 - 자동차 경주

### 구현할 기능 목록

- 사용자는 경주할 **자동차들의 이름**을 입력할 수 있다. 이는 쉼표(,)를 기준으로 구분된다.
  <br/>
  <br/>
- 이때, 자동차의 이름은 5자 이하만 입력 가능하며 5자를 초과하거나 공백이라면 ‘[ERROR]: 자동차 이름은 1자 이상, 5자 이하여야 합니다.’ 라는 Error와 함께 애플리케이션이 종료된다. <sub>예를 들어, 'pobi,,jae'나 ',,,A' 이런 식으로 입력이 들어오는 경우 쉼표를 기준으로 구분되어 생긴 공백을 방지하기 위함.</sub>
  <br/>
  <br/>
- 또한, 자동차 **경주**이기 때문에 입력된 문자열에서 쉼표가 하나도 없는 경우 ‘[ERROR]: 둘 이상의 자동차 이름을 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 사용자는 **자동차들의 이동 횟수**도 입력할 수 있다. 만약 이 값이 0이나 음수 등, 1 이상의 자연수가 아니면 ‘[ERROR]: 시도할 횟수는 1 이상의 자연수여야 합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
  - 이동 횟수나 이름이 어느 값도 없는 공백이라면 ‘[ERROR]: 이동 횟수(또는 자동차 이름)값을 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다. 두 값 모두 공백이라면 ‘[ERROR]: 값을 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
    <br/>
    <br/>
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
  <br/>
  <br/>
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
  <br/>
  <br/>
- 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
  <br/>
  <br/>
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
  <br/>
  <br/>
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
  <br/>
  <br/>

### 입출력 요구사항

**입력**

- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)

```js
pobi, woni, jun;
```

<br/>

- 시도할 횟수

```js
5;
```

<br/>

**출력**

- 차수 별 실행 결과

```js
pobi : --
woni : ----
jun : ---
```

<br/>

- 단독 우승자 안내 문구

```js
최종 우승자 : pobi
```

<br/>

- 공동 우승자 안내 문구

```js
최종 우승자 : pobi, jun
```

<br/>

**실행결과 예시**

```js
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```
